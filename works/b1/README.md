# b1 pseudo-labelled OBB dataset
Images: bucket hamimmahmud0/SAM_COCO_b1/b1/images (174 drone JPGs, 4000x3000, native resolution).
Labels: PSEUDO-labels (not human-verified) from yolo26l-obb trained on DRASHTI
(hamimmahmud0/yolo-obb-drashti-models/l1280/best.pt), tiled inference (1920 long side, 1280 tiles, 25%+ overlap), conf >= 0.5.
Format: Ultralytics OBB (`cls x1 y1 x2 y2 x3 y3 x4 y4`, normalized). 14 classes as in data.yaml.
Split: contiguous blocks by filename, 148 train / 26 val. Known issues: rooftop false positives (Truck/Trailer/Auto3WCargo) and class confusion
on these oblique views; review before using for training. Generated by works/yolo-obb-drashti/pseudo_label.py.
